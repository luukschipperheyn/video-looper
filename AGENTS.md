## Project docs

Read these before changing behavior or naming things:

- [`CONTEXT.md`](CONTEXT.md) — domain language. Use these terms; avoid the listed synonyms.
- [`docs/architecture.md`](docs/architecture.md) — as-is architecture, module map, and behavior.
- [`README.md`](README.md) — requirements, build, and run.

Decisions that touch the area you are about to change live in `docs/adr/`. If that directory or a file in it is missing, proceed.
