# Loop resolution is independent of the window

The Loop is resized with the window today, so moving it to another monitor or going fullscreen empties it and rebuilds it. The Loop gets its own resolution instead, 1280×720 by default, chosen at startup and unchanged during a set. The Program window and the Mac window only scale. Following the window was rejected because where a window sits must not decide whether the Loop survives, and a fullscreen 4K Loop costs about 8 GB.
